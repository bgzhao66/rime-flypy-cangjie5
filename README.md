# RIME flypy-cangjie5 -- 「雙拼逆倉」輸入法方案

## 說明
<code>flypy-cangjie5</code> 是一個基於雙拼和倉頡五代首尾碼逆序的音形輸入法方案，設計目標是讓用戶能夠簡單、快速、準確地統一輸入各種語言風格、文體的數百萬漢語字詞，包括但不限於現代文、古詩文、和文言文等等。

本方案的核心原則是**確定性編碼**：在碼表覆蓋範圍內，每一個合法編碼串都唯一對應一個詞條；沒有候選歧義，不需要數字鍵選詞，熟練後可以完全盲打。也就是說，用戶輸入的不是「一組候選」，而是「一個確定的詞」。

- **雙拼**：使用雙拼方案作為字詞的音碼部分，採用**小鶴雙拼**方案，每字兩碼。
- **倉頡**：利用倉頡**五代**速成碼的**逆序首尾**，作為區分碼，每字詞兩碼。

### 特點
- **零重碼，編碼唯一**：所有 1–7 字詞，當發生重碼時均按同一套詞頻順序碼規則消解；完整碼、簡碼，任意合法編碼串均唯一。根據百萬級詞庫統計，全部重碼組數為 0，最大重碼組為 1，靜態重碼率與動態選重率均為 0.00%，徹底告別數字鍵選詞。
- **可盲打，不中斷思路**：編碼基於靜態詞頻生成，碼表固定，不隨個人輸入習慣漂移；高頻字詞有簡碼，熟練後可肌肉記憶直出；即使偶爾需要看候選，候選也已縮小到唯一或少數確定項，補一位詞頻順序碼即可上屏。輸入節奏穩定，思路不被打斷。
- **超大詞庫**：詞庫規模達到**數百萬級**，涵蓋常用字詞及大量專業詞彙；這遠遠超過了傳統形碼、以及音形碼輸入法，如五筆等，可支持的詞庫規模。
- **高效輸入**：採用**全碼前綴**的方式，對高頻字詞逐級支持簡碼，提高輸入效率；其中，全音碼的簡碼，已涵蓋大部分高頻詞彙，僅偶爾需要輸入區分碼。

因此，該輸入法方案，同時達成了**超大詞庫**、**編碼唯一**、**高效輸入**的要求。這三個指標，該輸入法，均優於其他傳統輸入法方案。

## 編碼規則
該輸入法，編碼規則簡單、統一，以雙拼為基礎，僅在必要時以形碼作為區分碼；百分之九十以上的常用詞彙，僅使用雙拼簡碼就可以輸入。當需要額外輸入區分碼時，基於最少注意力轉移原則，首先選取尾字的倉頡尾碼，關注在當前注意力的焦點；如果還不能區分時，再考慮首字形碼特徵。所以，形碼區分碼的取碼順序為**逆序**。

**全碼**為「主碼+輔碼」。

### 主碼
主碼部分，由「雙拼」構成，參與取碼字每字兩碼，為全碼前綴。

* **單字、雙字詞、三字詞、和四字及以上詞**：每個字的雙拼「每字兩碼」。

### 輔碼
輔碼部分，由尾字以及首字倉頡碼構成，尾字取倉頡尾碼，首字取倉頡首碼，共不超過兩碼，為全碼後綴。

* **單字、雙字詞、三字詞**：在主碼後，加「尾字倉頡尾碼+首字倉頡首碼」。
* **四字及以上詞**：不取輔碼。

### 簡碼
按照**全碼前綴**的方式，按照詞頻從高到低，在沒有衝突的前提下，

* 依次對單字、雙字詞、三字詞，取 2*N-1 鍵、2*N 鍵、2*N+1 鍵簡碼，其中 N 為該詞的長度。
* 四字及以上詞不設簡碼。

### 順序碼
當全碼發生重碼時，將重碼組內詞條按靜態詞頻從高到低排序，第一位編碼保持不變，從第二位開始追加一位順序碼。
* 若該組最高頻詞**已有簡碼**，則首先把最高頻詞與次高頻詞交換位置，然後再添加順序碼。

## 安裝
此輸入法方案需要 [RIME | 中州韻輸入法引擎](https://rime.im/)

default.custom.yaml 文件為用戶重要配置文件，其中 schema_list 字段後是所有可選配方，可自行增刪（行首用“#”號註釋表示不引入）。

### 輸入法碼表
```
flypy_cangjie5.schema.yaml
flypy_cangjie5*.dict.yaml
```

### 通用方式
[安裝 rime](https://rime.im/) 後，把碼表複製到 Rime 用戶設定目錄，然後重新部署。
 部署位置：
##### Windows 10+
```
    %APPDATA%\Rime
```
##### Mac OSX
```
    ~/Library/Rime
```
##### Linux (部署後最好重啟一次)
###### ibus-rime:
```
    ~/.config/ibus/rime
```
###### fcitx-rime:
```
    ~/.config/fcitx/rime
```
###### fcitx5-rime:
```
    /usr/share/rime-data
```

### 字體
為顯示 CJK 擴展區數萬漢字，可下載並安裝 [HanaMin|花園明朝](https://glyphwiki.org/hanazono/hanazono-20170904.zip) 字體庫。
