# RIME flypy-cangjie5_simp —「双拼逆仓」输入法方案

## 方案简介

`flypy_cangjie5_simp`（双拼逆仓）是一套基于**小鹤双拼与仓颉五代逆序辅助码**的音形输入法方案。

本方案旨在让用户以简单、快速、准确且可控的方式，统一输入汉语各种文体中的数百万字词，包括但不限于现代汉语、古诗词、文言文等。它不以限定词库或特定语言风格为设计前提，而是通过可扩展的编码与消歧机制，兼顾日常输入效率与低频字词、古籍用语的准确定位。

本方案的核心原则是**确定性编码**：在码表覆盖范围内，每个词条均具有唯一的指定编码，不需要依赖候选词的排序与选择来消除同码歧义。熟练后，用户可以直接输入完整编码，实现盲打，减少选词对思路的干扰。

方案同时兼顾编码效率与学习成本：以成熟的小鹤双拼作为主码，以仓颉五代字形编码作为辅助码，仅在主码不足以唯一定位词条时追加辅助码；高频词则优先获得较短编码。

此外，本方案支持**双拼输入、全拼显示**，让用户以双拼提高输入效率，同时保留完整拼音直观、易读的呈现方式。

## 编码规则

### 1. 主码：小鹤双拼

采用小鹤双拼作为主码，每个汉字使用两个按键表示其拼音，词语则将各字的双拼码依次拼接。

主码提供主要的输入效率与较低的学习门槛。对于能够直接定位的词条，无须额外输入形码。

### 2. 辅助码：仓颉五代逆序

当主码与已分配的编码发生冲突时，按照「**Last → First → Second**」的次序，逐步追加仓颉辅助码，直到获得尚未分配的编码。

其中：

- **Last**：末字的仓颉尾码。
    
- **First**：首字的仓颉首码。
    
- **Second**：次字的仓颉首码。
    

具体规则如下：

|词条长度|辅助码追加顺序|
|---|---|
|单字|尾码 → 首码 → 次码|
|双字词|末字尾码 → 首字首码 → 次字首码|
|三字词|末字尾码 → 首字首码 → 次字首码|
|四字及以上|不追加仓颉辅助码，直接追加未使用的字母序号|

对于一至三字词，系统依上述次序逐步延长编码。当可用的仓颉辅助码不足以消除冲突时，再追加未被使用的字母序号，以确保编码的唯一性。

对于四字及以上的词条，则直接使用字母序号消除冲突，避免长词编码因额外的形码而变得更长。

### 3. 唯一编码与词频分配

所有词条依词频由高到低的顺序进行编码分配。

对每个词条，优先使用其主码；若该编码已被占用，则按照相应的辅助码规则逐步追加编码，直至获得尚未使用的编码。

因此，高频词优先获得较短的编码，低频词则在必要时使用较长编码。这种方式将编码长度与词频结合，在维持确定性编码的同时，提高整体输入效率。

### 4. 简码

仅一至三字词设有简码。

简码长度比相应词条的主码长度少一码，并依词频分配。分配时须避免与已分配的编码发生冲突。

简码进一步缩短高频词的输入长度，同时保留完整编码作为准确定位词条的手段。

### 5. 双拼输入、全拼显示

本方案支持**双拼输入、全拼显示**：用户使用小鹤双拼编码输入汉字，输入法则将相应的双拼码展开为完整拼音进行显示。

这使用户既能享受双拼输入的高效率，又能保留全拼显示直观、易读的特点。双拼负责提高输入效率，全拼显示则有助于阅读、校对与理解，无须为了使用双拼而牺牲拼音的完整呈现。

## 方案特点

- **确定性编码**：每个词条具有唯一指定编码，减少候选选择对输入流程的干扰。
    
- **音形结合**：以小鹤双拼为主码，结合仓颉五代逆序辅助码，兼顾易学性与准确性。
    
- **双拼输入、全拼显示**：以双拼提高输入效率，以完整拼音呈现输入结果，兼顾速度与可读性。
    
- **高频词优先**：依词频分配编码，让常用词优先获得较短的编码。
    
- **逐步消歧**：仅在编码冲突时追加辅助码，避免不必要的形码输入。
    
- **统一输入各种文体**：适用于现代汉语、古诗词、文言文及其他汉语书面语。
    
- **易于扩展**：通过追加辅助码与字母序号，可以为更多词条分配不重复的编码。
    
- **适合盲打**：熟练后可按照完整编码直接输入，无须依赖候选词选择。

## 安装

本方案以 RIME 中州韵输入法引擎为基础，支持通过手工复制配置文件或使用安装脚本完成安装。

### 1. 安装 RIME 引擎

首先，下载并安装 [RIME｜中州韵输入法引擎](https://rime.im/)。

安装后，以下将 RIME 的用户配置目录简称为 `<RIME>`。

不同操作系统及输入法前端的配置路径如下。

#### Windows 10 及以上版本

```
%APPDATA%\Rime
```

#### macOS

```
~/Library/Rime
```

#### Linux

**ibus-rime：**

```
~/.config/ibus/rime
```

**fcitx-rime：**

```
~/.config/fcitx/rime
```

**fcitx5-rime：**

```
~/.local/share/fcitx5/rime
```

Linux 用户安装完成后，如方案未能正常加载，可尝试重新启动输入法前端，再进行部署。

### 2. 手动配置

#### 注册输入法方案

编辑 `<RIME>/default.custom.yaml`，加入以下配置：

```
patch:
  schema_list:
    - {schema: flypy_cangjie5_simp}
```

如果原有配置已包含其他输入法方案，请将 `flypy_cangjie5_simp` 加入既有的 `schema_list`，而不是直接覆盖原有清单。

#### 安装码表与方案配置

将项目中的下列文件复制到 `<RIME>` 目录：

|来源文件|目标位置|
|---|---|
|`flypy_cangjie5_simp.schema.yaml`|`<RIME>/flypy_cangjie5_simp.schema.yaml`|
|`flypy_cangjie5_simp*.dict.yaml`|`<RIME>/flypy_cangjie5_simp*.dict.yaml`|

#### 安装插件

按照下表复制插件文件：

|来源文件|目标位置|
|---|---|
|`plugins/lua/*.lua`|`<RIME>/lua/*.lua`|
|`plugins/lua/rime.lua`|`<RIME>/rime.lua`|
|`plugins/latex/latex.*.yaml`|`<RIME>/latex.*.yaml`|
|`plugins/flypy_cangjie5_simp.custom.yaml`|`<RIME>/flypy_cangjie5_simp.custom.yaml`|

请按照项目实际目录结构复制文件，并保留原有的子目录结构要求。

#### 重新部署

完成方案注册、码表复制及插件安装后，执行 RIME 的「重新部署」，使配置生效。

### 3. 自动配置

若已安装 Git 与 Make，可在项目根目录获取所需子模块，然后进入 `tools` 目录执行安装：

```
git submodule update --init --recursive
cd tools
make install
```

在命令成功执行的前提下，安装脚本将自动识别 RIME 配置目录，安装码表与插件，并注册输入法方案。

安装完成后，执行 RIME「重新部署」，再选择 `双拼逆仓` 即可使用。

若安装失败，请检查 RIME 是否已正确安装、配置目录是否可写，以及 Git 子模块是否已完整获取。

## 字体

若需要显示 CJK 扩展区中的大量汉字，可安装 [HanaMin｜花园明朝字体](https://glyphwiki.org/hanazono/hanazono-20170904.zip)。

字体支持范围取决于所安装的版本；安装字体有助于显示更多汉字字形，但不会自动扩充输入法码表。某个汉字能否通过本方案输入，仍取决于码表是否收录相应字词及其编码。
