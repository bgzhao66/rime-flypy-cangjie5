# RIME flypy-cangjie5 —「雙拼逆倉」輸入法方案

## 方案簡介

`flypy-cangjie5`（雙拼逆倉）是一套基於**小鶴雙拼與倉頡五代逆序輔助碼**的音形輸入法方案。

本方案旨在讓用戶以簡單、快速、準確且可控的方式，統一輸入漢語各種文體中的數百萬字詞，包括但不限於現代漢語、古詩詞、文言文等。它不以限定詞庫或特定語言風格為設計前提，而是透過可擴展的編碼與消歧機制，兼顧日常輸入效率與低頻字詞、古籍用語的準確定位。

本方案的核心原則是**確定性編碼**：在碼表覆蓋範圍內，每個詞條均具有唯一的指定編碼，不需要依賴候選詞的排序與選擇來消除同碼歧義。熟練後，用戶可以直接輸入完整編碼，實現盲打，減少選詞對思路的干擾。

方案同時兼顧編碼效率與學習成本：以成熟的小鶴雙拼作為主碼，以倉頡五代字形編碼作為輔助碼，僅在主碼不足以唯一定位詞條時追加輔助碼；高頻詞則優先取得較短編碼。

此外，本方案支援**雙拼輸入、全拼顯示**，讓用戶以雙拼提高輸入效率，同時保留完整拼音直觀、易讀的呈現方式。

## 編碼規則

### 1. 主碼：小鶴雙拼

採用小鶴雙拼作為主碼，每個漢字使用兩個按鍵表示其拼音，詞語則將各字的雙拼碼依次拼接。

主碼提供主要的輸入效率與較低的學習門檻。對於能夠直接定位的詞條，無須額外輸入形碼。

### 2. 輔助碼：倉頡五代逆序

當主碼與已分配的編碼發生衝突時，依照「**Last → First → Second**」的次序，逐步追加倉頡輔助碼，直到取得尚未分配的編碼。

其中：

- **Last**：末字的倉頡尾碼。
    
- **First**：首字的倉頡首碼。
    
- **Second**：次字的倉頡首碼。
    

具體規則如下：

|詞條長度|輔助碼追加順序|
|---|---|
|單字|尾碼 → 首碼 → 次碼|
|雙字詞|末字尾碼 → 首字首碼 → 次字首碼|
|三字詞|末字尾碼 → 首字首碼 → 次字首碼|
|四字及以上|不追加倉頡輔助碼，直接追加未使用的字母序號|

對於一至三字詞，系統依上述次序逐步延長編碼。當可用的倉頡輔助碼不足以消除衝突時，再追加未被使用的字母序號，以確保編碼的唯一性。

對於四字及以上的詞條，則直接使用字母序號消除衝突，避免長詞編碼因額外的形碼而變得更長。

### 3. 唯一編碼與詞頻分配

所有詞條依詞頻由高到低的順序進行編碼分配。

對每個詞條，優先使用其主碼；若該編碼已被佔用，則依照相應的輔助碼規則逐步追加編碼，直至取得尚未使用的編碼。

因此，高頻詞優先獲得較短的編碼，低頻詞則在必要時使用較長編碼。這種方式將編碼長度與詞頻結合，在維持確定性編碼的同時，提高整體輸入效率。

### 4. 簡碼

僅一至三字詞設有簡碼。

簡碼長度比相應詞條的主碼長度少一碼，並依詞頻分配。分配時須避免與已分配的編碼發生衝突。

簡碼進一步縮短高頻詞的輸入長度，同時保留完整編碼作為準確定位詞條的手段。

### 5. 雙拼輸入、全拼顯示

本方案支援**雙拼輸入、全拼顯示**：用戶使用小鶴雙拼編碼輸入漢字，輸入法則將相應的雙拼碼展開為完整拼音進行顯示。

這使得用戶既能享受雙拼輸入的高效率，又能保留全拼顯示直觀、易讀的特點。雙拼負責提高輸入效率，全拼顯示則有助於閱讀、校對與理解，無須為了使用雙拼而犧牲拼音的完整呈現。

## 方案特點

- **確定性編碼**：每個詞條具有唯一指定編碼，減少候選選擇對輸入流程的干擾。
    
- **音形結合**：以小鶴雙拼為主碼，結合倉頡五代逆序輔助碼，兼顧易學性與準確性。
    
- **雙拼輸入、全拼顯示**：以雙拼提高輸入效率，以完整拼音呈現輸入結果，兼顧速度與可讀性。
    
- **高頻詞優先**：依詞頻分配編碼，讓常用詞優先獲得較短的編碼。
    
- **逐步消歧**：僅在編碼衝突時追加輔助碼，避免不必要的形碼輸入。
    
- **統一輸入各種文體**：適用於現代漢語、古詩詞、文言文及其他漢語書面語。
    
- **易於擴展**：透過追加輔助碼與字母序號，可以為更多詞條分配不重複的編碼。
    
- **適合盲打**：熟練後可依照完整編碼直接輸入，無須依賴候選詞選擇。

## 安裝

本方案以 RIME 中州韻輸入法引擎為基礎，支援透過手工複製配置檔案或使用安裝腳本完成安裝。

### 1. 安裝 RIME 引擎

首先，下載並安裝 [RIME｜中州韻輸入法引擎](https://rime.im/)。

安裝後，以下將 RIME 的用戶配置目錄簡稱為 `<RIME>`。

不同作業系統及輸入法前端的配置路徑如下。

#### Windows 10 及以上版本

```
%APPDATA%\Rime
```

#### macOS

```
~/Library/Rime
```

#### Linux

**ibus-rime：**

```
~/.config/ibus/rime
```

**fcitx-rime：**

```
~/.config/fcitx/rime
```

**fcitx5-rime：**

```
~/.local/share/fcitx5/rime
```

Linux 用戶安裝完成後，如方案未能正常載入，可嘗試重新啟動輸入法前端，再進行部署。

### 2. 手工配置

#### 註冊輸入法方案

編輯 `<RIME>/default.custom.yaml`，加入以下配置：

```
patch:
  schema_list:
    - {schema: flypy_cangjie5}
```

如果原有配置已包含其他輸入法方案，請將 `flypy_cangjie5` 加入既有的 `schema_list`，而不是直接覆蓋原有清單。

#### 安裝碼表與方案配置

將專案中的下列檔案複製到 `<RIME>` 目錄：

| 來源檔案                         | 目標位置                                |
| ---------------------------- | ----------------------------------- |
| `flypy_cangjie5.schema.yaml` | `<RIME>/flypy_cangjie5.schema.yaml` |
| `flypy_cangjie5*.dict.yaml`  | `<RIME>/flypy_cangjie5*.dict.yaml`  |

#### 安裝插件

依照下表複製插件檔案：

|來源檔案|目標位置|
|---|---|
|`plugins/lua/*.lua`|`<RIME>/lua/*.lua`|
|`plugins/lua/rime.lua`|`<RIME>/rime.lua`|
|`plugins/latex/latex.*.yaml`|`<RIME>/latex.*.yaml`|
|`plugins/flypy_cangjie5.custom.yaml`|`<RIME>/flypy_cangjie5.custom.yaml`|

請依照專案實際目錄結構複製檔案，並保留原有的子目錄結構要求。

#### 重新部署

完成方案註冊、碼表複製及插件安裝後，執行 RIME 的「重新部署」，使配置生效。

### 3. 自動配置

若已安裝 Git 與 Make，可在專案根目錄取得所需子模組，然後進入 `tools` 目錄執行安裝：

```
git submodule update --init --recursive
cd tools
make install
```

在命令成功執行的前提下，安裝腳本將自動識別 RIME 配置目錄，安裝碼表與插件，並註冊輸入法方案。

安裝完成後，執行 RIME「重新部署」，再選擇 `雙拼逆倉` 即可使用。

若安裝失敗，請檢查 RIME 是否已正確安裝、配置目錄是否可寫，以及 Git 子模組是否已完整取得。

## 字體

若需要顯示 CJK 擴展區中的大量漢字，可安裝 [HanaMin｜花園明朝字體](https://glyphwiki.org/hanazono/hanazono-20170904.zip)。

字體支援範圍取決於所安裝的版本；安裝字體有助於顯示更多漢字字形，但不會自動擴充輸入法碼表。某個漢字能否透過本方案輸入，仍取決於碼表是否收錄相應字詞及其編碼。
