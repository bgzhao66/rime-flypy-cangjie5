# RIME flypy-cangjie5-simp -- 「双拼逆仓」输入法方案

## 说明
<code>flypy-cangjie5-simp</code> 是一个基于双拼和仓颉五代首尾码逆序的音形输入法方案，设计目标是让用户能够简单、快速、准确地统一输入汉语任意语言风格、各种文体的数百万字词，包括但不限于现代文、古诗文、以及文言文等等。

本方案的核心原则是**确定性编码**：在码表覆盖范围内，每一个合法编码串都唯一对应一个词条，熟练后可以完全盲打。

- **双拼**：使用双拼方案作为字词的音码部分，采用**小鹤双拼**方案，每字两码。
- **仓颉**：利用仓颉**五代**速成码的**首尾逆序**，作为区分码，每词两码。
- **简码**：依据调整后的静态词频，逐级统一生成唯一的**基于前缀**的简码。
- **顺序码**：当「双拼+仓颉首尾码逆序」依然不足以**确定唯一**的字词时，依据静态词频按需增加一位顺序码。

### 特点
- **零重码，编码唯一**：所有 1–7 字词，当发生重码时均按同一套词频顺序码规则消解；完整码、简码码，任意合法编码串均唯一。根据百万级词库统计，全部词长重码组数为 0，最大重码组为 1，静态重码率与动态选重率均为 0.00%，彻底告别数字键选词。
- **可盲打，不中断思路**：编码基于静态词频生成，码表固定，不随个人输入习惯漂移；高频字词有简码，熟练后可肌肉记忆直出；即使偶尔需要看候选，候选也已缩小到唯一或少数确定项，补一位词频顺序码即可上屏。输入节奏稳定，思路不被打断。
- **超大词库**：词库规模达到**数百万级**，涵盖常用字词及大量专业词汇；这远远超过了传统形码、以及音形码输入法，如五笔等，可支持的词库规模。
- **高效输入**：采用**全码前缀**的方式，对高频字词逐级支持简码，提高输入效率；其中，全音码的简码，已涵盖大部分高频词汇，仅偶尔需要输入区分码。

因此，该输入法方案，同时达成了**超大词库**、**编码唯一**、**高效输入**的要求。这三个指标，该输入法，均优于其他传统输入法方案。

## 编码规则
该输入法，编码规则简单、统一，以双拼为基础，仅在必要时以形码作为区分码；百分之九十以上的常用词汇，仅使用双拼简码就可以输入。当需要额外输入区分码时，基于最少注意力转移原则，首先选取尾字的仓颉尾码，关注在当前注意力的焦点；如果还不能区分时，再考虑首字形码特征。所以，形码区分码的取码顺序为**逆序**。

**全码**由为「主码+辅码」。

### 主码
主码部分，由「双拼」构成，参与取码字每字两码，为全码前缀。

* **单字、双字词、三字词、和四字及以上词**：每个字的双拼「每字两码」。

### 辅码
辅码部分，由尾字以及首字仓颉码构成，尾字取仓颉尾码，首字取仓颉首码，共不超过两码，为全码后缀。

* **单字、双字词、三字词**：在主码后，加「尾字仓颉尾码+首字仓颉首码」。
* **四字及以上词**：不取辅码。

### 简码
按照**全码前缀**的方式，按照词频从高到低，在没有冲突的前提下，

* 依次对单字、双字词、三字词，取 2*N-1 键、2*N 键、2*N+1 键简码，其中 N 为该词的长度。
* 四字及以上词不设简码。

### 顺序码
当全码发生重码时，将重码组内词条按静态词频从高到低排序，第一位编码保持不变，从第二位开始追加一位顺序码。
* 若该组最高频词**已有简码**，则首先把最高频词与次高频词交换位置，然后再添加顺序码。

## 安装
此输入法方案需要 [RIME | 中州韵输入法引擎](https://rime.im/)

default.custom.yaml 文件为用户重要配置文件，其中 schema_list 字段后是所有可选配方，可自行增删（行首用“#”号注释表示不引入）。

### 输入法码表
```
flypy_cangjie5_simp.schema.yaml
flypy_cangjie5_simp*.dict.yaml
```

### 通用方式
[安装 rime](https://rime.im/) 后，把码表复制到 Rime 用户设定目录，然后重新部署。
 部署位置：
##### Windows 10+
```
    %APPDATA%\Rime
```
##### Mac OSX
```
    ~/Library/Rime
```
##### Linux (部署后最好重启一次)
###### ibus-rime:
```
    ~/.config/ibus/rime
```
###### fcitx-rime:
```
    ~/.config/fcitx/rime
```
###### fcitx5-rime:
```
    /usr/share/rime-data
```

### 字体
为显示 CJK 扩展区数万汉字，可下载并安装 [HanaMin|花园明朝](https://glyphwiki.org/hanazono/hanazono-20170904.zip) 字体库。
